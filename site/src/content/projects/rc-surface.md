## RC Surface

A <a class="entity-link" href="https://www.ableton.com/en/live/max-for-live" target="_blank" rel="noopener noreferrer">Max4Live</a> device for <a class="entity-link" href="https://www.ableton.com" target="_blank" rel="noopener noreferrer">Ableton Live</a>, open-source MIT. Turns any phone browser into a wireless MIDI + multi-sensor controller: 12 performance pads, two physics XY pads, knobs & faders, sensor mappings (motion, orientation, audio, vision), in-browser mapping editor. No phone install required.

Built on the Ableton Extensions SDK. The mobile side runs as a web app on the phone's browser; the desktop side runs as a Max4Live device inside Live. Both talk over WebSocket, and the mapping editor lives in the browser too — so you can build or change a layout from the phone while Live is on stage.
