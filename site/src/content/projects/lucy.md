## LUCY

LUCY is the umbrella for an ongoing body of generative audiovisual work I publish under the same pseudonym across [Teia](https://teia.art/lucy) and [fxhash](https://www.fxhash.xyz/u/nt_worm). It started as a single autonomous automaton built in <a class="entity-link" href="https://cycling74.com/products/max" target="_blank" rel="noopener noreferrer">Max</a> that composes its own audiovisual pieces: generative music with custom sample pools (Korg, FM modulation, hardware synths) plus Hydra.js visuals reactive to the audio.

The system uses a probabilistic MIDI control layer inside <a class="entity-link" href="https://www.ableton.com" target="_blank" rel="noopener noreferrer">Ableton Live</a>: scale maps with alternative tunings, real-time transitions between sections, and a final mix pass that watches for frequency masking and phase cancellation. Each OBJKT on Teia is a captured run of that machine — never the same twice. Sixteen published editions, including LUCY THEME 1–3 and LUCY MK1001–MK1007.
