## fxhash — trabalho generativo como nt_worm

Cerca de trinta peças no [arquivo do fxhash](https://killedbyapixel.github.io/fxhashArchive/#/artist/tz1du7JyqkpAWrQf7kspXS383wpMxkVWCoqQ), todas com <a class="entity-link" href="https://hydra.ojack.xyz" target="_blank" rel="noopener noreferrer">Hydra.js</a> nos visuais e Web Audio API + OSC na reatividade sonora. O conjunto se move entre dois polos: loops ambient guiados por análise de áudio e composições movidas a glitch que partem dos mesmos patches de Hydra, mas tratam o canvas como um espaço de decisão quadro a quadro.

KAKOFONI ORQUESTRA (edição #37 adquirida pelo Madison Museum) e as faixas de <a class="entity-link" href="/pt-br/work/lucy">LUCY</a> são as peças que têm página própria neste site. O arquivo completo está no link do perfil acima.

É também o laboratório informal de pesquisa das peças maiores — quase tudo o que aprendo aqui sobre Hydra + Web Audio acaba voltando para <a class="entity-link" href="/pt-br/work/lucy">LUCY</a> ou para um show ao vivo.
