# Perfil

Estas pastas são cópias legadas dos materiais profissionais usados pelo portfólio:

- `cv-gabriel/`: currículos, masters, documentos e scripts do CV.
- `meu-perfil-online/`: briefs, plataformas, produção e referências do perfil online.

O repositório canônico é `C:/Users/Usuario/repos/plano_de_carreira`. Faça nele qualquer atualização de currículo, perfil profissional, prospecção ou planejamento de carreira.

O site continua pertencendo ao repositório `portfolio`. As cópias legadas deste diretório foram mantidas como recuperação adicional; metadados Git, worktrees, caches, logs e artefatos gerados permanecem ignorados aqui.
